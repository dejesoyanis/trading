# Tests

Cargo runs tests that live inside each crate. `cargo test --workspace --locked` is the local unit-test command. It does not need Docker or PostgreSQL, and it does not run ignored tests.

`crates/trading-domain/tests/adfr_reconciliation.rs` checks the ADFR register, the source manifest, the 2026-11-15 decision records, and the TRD-ARCH-03A status-model draft, including the ARCH-DEC-04 through ARCH-DEC-08 interpretation constraints, the ARCH-DEC-09 through ARCH-DEC-20 OMS design-policy record, the unratified TRD-ARCH-03B.2 risk proposal index, the ARCH-DEC-21 through ARCH-DEC-34 risk design-policy record, and the unratified TRD-ARCH-03B.3 broker proposal index. The policy records are not an implementation. The historical risk proposal index stays `NOT_RATIFIED`. The later risk policy is not a predicate, not a release, and not a posting. The broker proposal index is not a uniqueness proof, not a completeness proof, and not a dispatch. The ARCH-DEC-35 through ARCH-DEC-48 broker design-policy record is not an implementation, not broker evidence, and not a completeness proof. The historical broker proposal index stays `NOT_RATIFIED`. The TRD-ARCH-03B.4 IBKR evidence plan is not broker evidence, not a ratification, and not an executed test. Every external case in that plan stays `NOT_EXECUTED`. These files do not implement trading behavior, and they do not pass B10-T01 through B10-T12. The draft under `contracts/status-model/` is not a wire schema. An ignored PostgreSQL test is not a pass. Remote CI is not run by this file.

The PostgreSQL test is `crates/trading-persistence/tests/connectivity.rs`. `cargo test --workspace` leaves it ignored. GitHub Actions runs it with `--ignored` when `TRADING_ALLOW_DATABASE_INTEGRATION_TESTS=1` and `TRADING_TEST_DATABASE_URL` names a database whose name contains `_test`. The command is documented in [the development guide](../docs/development/README.md).
